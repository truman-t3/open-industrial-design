# Open Industrial Design Trademark & Brand Policy — Draft

Open Industrial Design Community source code is licensed under the Mozilla Public License 2.0.

The source-code license does **not** automatically grant permission to use the official Open Industrial Design brand in a way that implies endorsement or official status.

## Brand assets

The following are treated separately from the MPL-2.0 code license:

- Open Industrial Design name;
- official logo;
- application icon;
- official wordmark;
- distinctive official brand artwork.

## Generally acceptable references

Factual references are intended to be allowed, for example:

```text
Forked from Open Industrial Design
Compatible with Open Industrial Design
Plugin for Open Industrial Design
Built using Open Industrial Design
```

provided the use does not imply official endorsement.

## Uses requiring care or permission

A fork or third-party product should not present itself as:

```text
the official Open Industrial Design
Open Industrial Design official edition
```

or reuse official visual identity in a confusing manner without permission.

## Open-source code vs brand

```text
MPL-2.0 source code ≠ automatic trademark license
```

Before formal trademark registration or significant commercial launch, obtain jurisdiction-specific legal review.
