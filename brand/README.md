# Open Industrial Design Brand Assets

Canonical raster assets for Open Industrial Design.

## Primary logo

- `logo/open-industrial-design-logo-primary.png` — light backgrounds
- `logo/open-industrial-design-logo-dark.png` — dark backgrounds
- `logo/open-industrial-design-logo-black.png` — monochrome black
- `logo/open-industrial-design-logo-white.png` — monochrome white

## App / repository icon

Sizes are provided from 1024 px down to 16 px under `icon/`.

Use `icon/open-industrial-design-icon-1024.png` as the raster master for development.

## GitHub

- Repository/avatar icon: `social/open-industrial-design-github-avatar.png`
- Brand kit board: `social/open-industrial-design-brand-kit-board.png`
- Brand guide board: `social/open-industrial-design-brand-guide-board.png`

The brand boards are reference-only and should not be used as runtime assets.

## Canonical naming

`Open Industrial Design`

Recommended descriptor:

`Open Industrial Design — Open-source Industrial Design Workspace`

Chinese descriptor:

`Open Industrial Design｜开源工业设计工作台`

## Vector status

These are high-resolution transparent PNG assets, not true vector masters.

Before trademark filing, app-store release, or large-format print production, reconstruct and visually validate an SVG master rather than treating the raster source as final vector artwork.
