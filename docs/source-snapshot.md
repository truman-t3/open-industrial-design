# 内部源码快照打包与核验

## 已确定的正式交付渠道

2026-10-05，已通过 GitHub 插件核实[源码仓库](https://github.com/truman-t3/open-industrial-design)为公开仓库，且 `v0.1.0-alpha.1` 源码预发布已存在。本轮准备 `v0.1.0-alpha.2`；新版本是否发布以 Releases 为准。源码公开不自动关闭编译成品的对应提交字节和声明绑定门槛。推送前核对目标仓库，只上传审核过的文件清单，不上传整个工作区、API Key、私人项目、浏览器资料或内部 QA 记录。

发布前应准备适合公开的仓库内容（不直接上传整个工作目录或内部 ZIP），核对源码、构建说明、锁文件、MPL-2.0 与第三方声明，排除凭据、用户工程、QA 数据和仅供参考的非发布素材，同时确保移除这些素材后构建清单仍可用。生成的成品应能对应到该仓库的确定提交或标签。最终公开仓库地址和发布版本需要在实际发布时核验。

## 发布文件预检

公开候选文件集合单独保存在 `scripts/public-files.json`，不自动跟随内部归档清单扩张。运行 `pnpm.cmd run publication:check -- --public` 检查该集合；增加 `--staged` 可在实际 Git 仓库建立后检查暂存字节。公开候选排除两张参考展示板和两份内部工作记录，保留运行时图片、源码、测试、锁文件与原始声明。公开开发入口改为 `docs/release-status.md`，历史文档的内部 QA 记录不再提供失效下载链接。文件集合测试会核对 Markdown 内联文件链接的目标是否包含在候选中；不验证外部网址、标题锚点或图片内容。

此清单只是发布候选，不是分发授权。原有 `source:bundle` 继续使用内部清单；不要把其 ZIP 当作公开候选。公开候选副本中的内部归档命令会因缺少内部文件而拒绝执行，这是预期边界；开发、测试和生产构建不应依赖这些内部文件。

运行 `pnpm.cmd run publication:check` 只读检查当前显式文件清单；运行 `pnpm.cmd run publication:check -- --staged` 还会比对 Git 暂存区与已检查工作文件的原始字节，拒绝清单外文件、不同字节和非普通文件。脚本不会暂存、提交、推送或读取用户工程。输出只包含问题类型、文件与行号，不输出匹配到的疑似密钥。`publication:test` 已纳入质量检查，覆盖路径／链接、参考素材、内容筛查、暂存与工作文件不一致。

当前清单仍是内部归档用途，所以预检应返回 `BLOCKED`：两张参考板、内部任务状态和画布实施记录尚未整理成可公开内容。不要为了让命令变绿就修改这些文件的分类；需要另行审阅公开文件集合，并验证对应构建。即使文件预检无问题，也只代表有限模式筛查通过，不代替完整密钥审计、图像内容审核、第三方许可或正式发布批准。

此流程把当前工程保存为可逐文件核对的内部源码 ZIP，便于后续配套正式分发准备。它不上传文件，不提供公开下载地址，也不自动解除许可、图片授权或对应源码获取方式的发布门槛。

## 生成快照

在仓库根目录执行：

```powershell
pnpm.cmd run source:test
pnpm.cmd run source:bundle
```

固定输出为 `artifacts/source/open-industrial-design-source.zip`，始终位于本工作区，不带时间戳；重跑会更新这一份生成文件。修改源码后需重新生成，不能把旧快照作为新构建的对应源码。

归档只读取 [显式文件清单](../scripts/source-files.json)，包含应用与各工作区源码、测试、构建脚本、版本锁文件、已登记品牌和示例素材、许可原文及固定 Draco 文件。无 `node_modules`、构建成品、环境配置、API Key 文件、私人 `.oidproj`、浏览器资料或 QA 日志。已登记素材保留当前内部构建用途，授权状态未变，不代表可以对外分发。

清单有意不自动收集新文件。新增编译、测试或构建输入时，应审阅后把其仓库相对路径加入清单；不要加入整个用户目录。脚本拒绝越级路径、敏感路径、链接文件／链接父目录，缺少列出的文件也会报错。路径白名单不是内容级密钥扫描，不应在源码中硬编码凭据。

## 校验和还原

ZIP 内的 `SOURCE_BUNDLE_MANIFEST.json` 记录每个文件的大小和 SHA256。脚本在写入前及写入后解包核对文件集合和字节；同一组输入使用固定顺序和 ZIP 时间字段，重复生成应得到相同哈希。哈希用于一致性检查，不是作者签名或可信来源认证。

解压到工作区中的独立空目录后，使用锁定版本安装依赖并执行检查：

```powershell
pnpm.cmd install --frozen-lockfile
pnpm.cmd run release:check
```

安装依赖可能需要网络。ZIP 不包含第三方包管理器缓存，也不是第三方全部对应源码包；草图字体从锁定的安装依赖取得，固定 Draco 解码器从归档内取得。第三方字体来源和源码义务仍以运行时资产复核记录为准。

文档中的历史工作区 QA 链接不包含在这个源码 ZIP 中；它们用于本机审阅，不是构建输入。正式发布前仍需确定接收者可取得精确对应源码的方式，并补齐其余授权及声明审核。
