# Community Alpha 发布状态

当前版本为 `0.1.0-alpha.1`，处于发布准备阶段，尚未完成正式公开发布。架构规划中的未来功能不是已实现能力；现有能力和使用限制以 [README](../README.md) 和 [使用指南](./community-alpha-quickstart.md) 为准。

## 已完成的技术核验

本地质量检查覆盖格式、lint、类型、自动测试和生产构建。工程导入已增加跨项目数据归属检查及解压大小限制；运行时改用本地字体和 Draco 资源。两张仅作参考的展示板不进入网页成品，源码不包含它们时也能构建。自动测试不能替代全部浏览器、中文输入法、实体键鼠或外部模型能力验收。

- 2026-10-03 已移除 Drei，3D 相机改用现有 Three.js 官方 OrbitControls；其独占依赖 maath、stats-gl、MediaPipe 等不再安装或进入当前依赖清单。当前生产清单 263 个包版本，缺少包级声明的项目为 0；历史调查不作为当前安装清单。资产和源码渠道门槛仍独立保留。

## 尚未关闭的发布事项

- 图片：13 张品牌图已有所有者原创声明，8 张示例图已有 AI 生成来源说明，不再统一写成“来源不明”。仍需确定接收者使用／再分发这些素材的范围；代码 MPL 不自动替图片选定许可。两张参考板继续排除。
- 运行时资产：字体替换、原文收集、本地托管和断网核验已完成；两类资产的分发记录仍待收口，不需要重新向开源作者请求许可。
- 核对实际 GitHub 账号和目标仓库，以确定提交或标签提供匹配源码；当前尚无已核验的公开仓库地址。
- 完成目标浏览器发布验收。构建仍有大分块警告，性能拆分另行安排。

当前资产检查器仅接受待审核状态，尚未实现有证据支撑的审核完成分支。因此反复执行 `notices:check` 不会自动解除这些事项。后续应先确认素材使用范围，再以证据更新登记、校验和回归测试；不能删除检查或批量把 pending 改成 approved 来绕过门槛。

## 开发与验收入口

执行 `pnpm run release:check` 进行技术质量检查；`pnpm run notices:check` 是独立的分发资料门槛，目前仍应报告未完成项。文件内容预检通过同样不代表许可或正式发布通过。

继续开发前阅读 [执行规则](./codex-rules.md)、[架构](./architecture.md) 和 [数据模型](./data-model.md)，仅执行当前明确分配的任务。内部工作日志、用户项目、凭据和 QA 原始记录不随公开源码交付。历史复核文档中的内部记录名称只用于说明证据来源，不是可下载附件。
