# Windows 桌面原型

此原型验证“不安装开发环境即可启动”的路径，尚不是正式便携版。使用 Electron 44.5.1 的 Windows x64 运行时加载本地构建，不依赖 Vite 预览端口。它不改变现有 Web 应用架构，也不替代路线图中的长期桌面技术决策。

## 本地启动

当前工作区中的程序是 `../artifacts/desktop/Open Industrial Design Desktop Preview/Open Industrial Design.exe`。双击即可启动，无需安装 Node 或 pnpm。它尚未签名；不要将此原型作为正式发行包转发。

程序默认将项目、缓存和日志放在程序目录旁边的 `Open Industrial Design Data`，本工作区位于 G 盘。菜单“项目 → 打开数据目录”可查看。也可启动时指定 `--data-dir=绝对路径`，首次使用必须是独立空目录。路径不可写时明确报错，不会主动改用 AppData；这并不保证操作系统或运行时完全不产生系统临时文件。

浏览器项目不会自动迁移到桌面端。请先在浏览器导出 `.oidproj`，再在桌面端导入。升级只替换程序目录，保留旁边的数据目录。不要直接分享整个数据目录，其中可能包含记住的 API Key；分享项目请使用项目导出。

## 验证范围

`pnpm desktop:test` 检查资源路径边界、固定应用来源、数据目录归属和重启保留。桌面窗口关闭 Node 集成，启用上下文隔离与沙箱，禁止新窗口、网页跳转和默认权限请求，没有向网页暴露本地文件操作桥梁。

本地 Electron 自动化已检查首页、打开示例画布、画布截图和重启后的本地存储保留。测试使用独立的 `artifacts/desktop/QA Data`，没有操作浏览器原项目或发起付费模型请求。
