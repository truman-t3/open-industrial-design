## 草图字体的远程路径

当前 Sketch adapter 没有设置 `window.EXCALIDRAW_ASSET_PATH`。已安装 Excalidraw 0.18.1 的字体 URL 生成器会追加 `https://esm.sh/@excalidraw/excalidraw@0.18.1/dist/prod/` 作为回退地址；文字字体选择或导出可能触发下载。[官方自托管说明](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/installation) 也明确默认 CDN 行为。

安装包的字体目录有九个系列、234 个文件：Assistant 4、Cascadia 1、ComicShanns 4、Excalifont 7、Liberation 1、Lilita 2、Nunito 5、Virgil 1、Xiaolai 209。数量来自本地文件枚举，**不表示一次编辑会下载全部字体**。现有四个 Assistant 的版权／OFL 绑定仍有效，但不能替代其他八个系列的精确许可文本与远程文件核验。

后续应核对实际需要的字体和版本，再决定本地托管范围；保留相应原文，并在隔离浏览器中禁用外网、使用文字与中文字体、导出 PNG。不能仅凭本地依赖安装完成就宣称草图完全离线。清单保存字体加载器源码哈希，构建离线复核它是否仍是当前版本。

[后续原文核验](./runtime-asset-notices.md) 已把 234 个本地文件匹配到固定提交，累计补充七个系列／229 个文件的原文或明确声明与官方正文；Liberation Sans 1.05 旧版完整许可仍缺失。Lilita 两种保留名称写法分别保留，适用性仍需审阅。文本收集不能以 Assistant 声明替代其他字体许可，也不解除远程文件核验和分发授权门槛。

## 3D 解码器的远程路径

当前查看器调用 `useGLTF(modelUrl)`，未覆盖 Draco 路径。已安装 Drei 10.7.8 的 [Gltf 上游实现](https://github.com/pmndrs/drei/blob/v10.7.8/src/core/Gltf.tsx) 与本地文件均把默认目录设为 `https://www.gstatic.com/draco/versioned/decoders/1.5.5/`。本地 three-stdlib 加载器仅在模型声明 `KHR_draco_mesh_compression` 时初始化该解码器；未压缩的最小三角形 GLB 验收不能覆盖这个分支。

安装的 `draco3d@1.5.7` 与远程目录的 `1.5.5` 不同。已收集的 1.5.7 包原文不能直接当作远程字节的出处。初次盘点只记录准确路径、条件及加载器源码哈希，没有下载、更换解码器或改变 3D 功能；随后完成的原文与实际字节核验见下方，压缩 GLB 的断网验收仍待完成。

用户导入模型可能另带外部纹理／缓冲 URI，Excalidraw 的外部素材库与 BYOK 地址也不在这个固定资产清单内。它不是所有网络请求的穷尽审计，不读取用户 Provider 设置或模型内容来制作公开清单。

后续已收集 Draco 1.5.5 固定提交的完整 LICENSE，原始附录一并保留；2026-10-02 又确认 CDN 的三份 JS／WASM 文件大小和 Git blob 指纹全部匹配该版本固定提交，详见[版本对应记录](./runtime-asset-notices.md#draco-版本对应)。这是实际字节快照核验，不保证未来响应，也不代表本地托管、压缩 GLB 断网验收或分发授权已完成；远程资产门槛保持待办。

## 构建检查与发布边界

[离线资产检查](../scripts/release-assets.mjs) 已接入许可采集。`dist/licenses/notice-inventory.json` 新增 `assetReview`，记录固定图片、来源说明、待授权清单、进入构建的两张参考板及两类待复核远程路径。构建保持原有八份声明输出；不会把 QA 日志、用户工程或凭据加入声明包。

`pnpm.cmd run notices:check` 除原有包声明、字体及对应源码要求外，还拦截未完成的图片授权、远程资产复核或缺少资产核验字段。当前预期失败：4 个包声明、对应源码获取方式、23 张图片授权、2 类远程资产复核待完成。此处数量是分发资料待办，不是新增的 23 个软件错误，也不表示依赖或图片已被认定禁止使用。

资产授权字段暂不提供自动批准路径；要改变其状态，应先确定真实来源、适用条款和项目所有者授权，再更新核验规则与证据。本轮不编造版权归属、不替所有者选择资产许可、不创建公开源码下载地址，也不对外发布。
