## 已适配

- 候选评审支持主图对照和两个候选并排，编号及视角标签明确操作对象；对比选择不持久化、不触发生图。采纳或丢弃当前候选后关闭评审，不自动将下一张设为操作对象；事务执行期间锁定全部候选操作。
- 在生成节点 Inspector 选择八个可编辑任务方向：草图渲染、造型融合、设计语言迁移、造型探索、CMF、视角探索、场景表达、局部编辑。
- 模板只填写方向，不调用 Provider；真实运行继续通过 Action / Router，依赖模型的多图编辑能力。
- 灯具示例展示「草图／参考 → 渲染步骤 → 主方案 → CMF／细节／场景分支」，使用既有图片并标注示例素材。模板只在明确打开示例时创建，不覆盖已保存工程、不伪造模型生成历史。用户保留的预览工程另外包含真实和明确标注的模拟验收分支，不等于初始模板。
- 未采纳候选是有稳定 ID、独立位置和输出边的 Board 结果节点，候选元数据与本地 Blob 分开保存；移动操作卡不带动结果。选中结果展示专属评审面板，不回退到任务配置。
- 候选可直接继续探索：统一 Action 创建操作卡并把该结果连为主图，不自动生成、不要求先采纳。实际运行读取该候选自身 Blob，并在请求前保存不可变输入快照。已有下游输入连接时，存储层阻止直接丢弃候选；历史快照在源候选不再存在时仍可恢复和导出。
- 采纳为方案或参考图原子更新同一个结果节点，保留 ID、位置、尺寸和连接；资源／Blob／必要 Design 血缘在同一 Dexie 事务中保存。正式血缘仅由 parentDesignId 决定；工作流边不写入 DesignRelation。无设计来源时采纳为 Concept，有来源时为 Variant，参考图不创建 Design。
- 操作卡就地编辑要求，高级参数留在 Inspector；修改输入只标记旧结果，不自动收费重跑。选中分支强调连线，其余连线降低强调。端口拖线、节点独立拖动、空格临时平移、缩放比例与查看全部采用同一画布交互体系。
- 保留现有候选采纳、丢弃、本地恢复及设计血缘，不自动覆盖源设计。
- 多视角任务可选择 1–4 个视角，Action 按所选视角顺序逐次执行图像编辑（每次一张），共用主图与参考图；全部成功后保存带视角标签的候选。中途失败不保存半套候选，也不自动重试；已经完成的外部请求仍可能计费。
- Canvas、Inspector 和候选评审显示视角标签；修改所选视角会令既有候选过期，不会自动生成。几何一致性仍需设计师评审，不能等同 CAD 或可靠三维重建。
- 局部编辑支持在当前主图预览上拖动矩形选区。选区绑定主图节点和素材，保存及刷新后恢复；更换素材后需重新框选。运行时将主图和同尺寸透明区域蒙版编码为 PNG Blob，通过 Action / Router 发送真实 mask，不能退化为无蒙版请求。
- Provider 设置需明确确认模型支持蒙版；连接测试不代表已验证图像编辑／多图／蒙版效果。接口拒绝时不重试、不降级。模型蒙版仅是指引；当前软件另将同尺寸返回图按矩形合成，保留选区外源图像素。损坏图片或尺寸不一致拒绝保存该批结果，不自动重跑；选区内语义、造型和接缝仍需评审，画笔及多边形选区尚未实现。
- 当前项目文件 schema 为 7，Dexie 数据库版本为 5（两个不同版本）。schema 0/1/2/3/4 等旧格式通过版本链迁移；新增独立候选节点、输出边、实际输入快照及 Blob 纳入工程包。未来不支持的格式明确拒绝，完整性校验在替换项目之前执行。

## 尚未移植

- 图案定位、抠图、消除、超分辨率：需独立能力契约和可验证的模型支持，不能用提示词模板冒充。
- 多视角几何一致性：已接通逐视角任务，但未完成真实模型多视角几何一致性验收，不保证普通图像编辑获得几何一致结果。
- 3D 生成、音视频生成：现有 3D 查看器不是生成服务。
- Canvas Agent、MCP、远程插件、自定义执行脚本：涉及新权限与运行时边界，不能直接并入现有应用。
- 小地图、分组、批量网格对比、提示词库：仍需分批实现与验收。
