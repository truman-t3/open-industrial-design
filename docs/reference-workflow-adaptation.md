### 当前工作流

- 候选评审支持主图对照和两个候选并排，编号及视角标签明确操作对象；对比选择不持久化、不触发生图。采纳或丢弃当前候选后关闭评审，不自动将下一张设为操作对象；事务执行期间锁定全部候选操作。
- 生成节点 Inspector 当前提供 16 个工具入口（`generation-tools.ts`）；既包含可编辑任务方向，也包含带明确参数／能力边界的图案、局部 CMF、抠图、消除等模式。入口数量不是专用模型数量。
- 模板只填写方向，不调用 Provider；真实运行继续通过 Action / Router，依赖模型的多图编辑能力。
- 灯具示例展示「草图／参考 → 渲染步骤 → 主方案 → CMF／细节／场景分支」，使用既有图片并标注示例素材。模板只在明确打开示例时创建，不覆盖已保存工程、不伪造模型生成历史。用户保留的预览工程另外包含真实和明确标注的模拟验收分支，不等于初始模板。
- 未采纳候选是有稳定 ID、独立位置和输出边的 Board 结果节点，候选元数据与本地 Blob 分开保存；移动操作卡不带动结果。选中结果展示专属评审面板，不回退到任务配置。
- 候选可直接继续探索：统一 Action 创建操作卡并把该结果连为主图，不自动生成、不要求先采纳。实际运行读取该候选自身 Blob，并在请求前保存不可变输入快照。已有下游输入连接时，存储层阻止直接丢弃候选；历史快照在源候选不再存在时仍可恢复和导出。
- 正式图片与候选使用相同的十五项图片继续探索入口：十项常用操作直接显示，抠图／消除／造型融合／设计语言迁移／图案定位放入默认折叠的“更多图片工具”。创建仍只连接来源、设置任务，不调用模型；纯文字起稿单独创建。浏览器已核对五个补充入口的任务、主图边和刷新恢复。
- 采纳为方案或参考图原子更新同一个结果节点，保留 ID、位置、尺寸和连接；资源／Blob／必要 Design 血缘在同一 Dexie 事务中保存。正式血缘仅由 parentDesignId 决定；工作流边不写入 DesignRelation。无设计来源时采纳为 Concept，有来源时为 Variant，参考图不创建 Design。
- 生成时只有明确的主图输入可提供来源 Design 与 DNA，候选主图沿用其记录的来源；补充参考图不决定父方案。没有主图方案来源时，即使参考图关联正式方案，也不将结果记为该参考的派生方案。新生成遵循该规则，不静默改写旧记录。
- 操作卡就地编辑要求，高级参数留在 Inspector；修改输入只标记旧结果，不自动收费重跑。选中分支强调连线，其余连线降低强调。端口拖线、节点独立拖动、空格临时平移、缩放比例与查看全部采用同一画布交互体系。
- Design DNA 可在方案检查器编辑六项保留约束和按行说明，显式保存经过领域 Action，不自动运行；新请求读取主图方案的当前 DNA，修改后旧候选显示过期，历史和已有子方案不变。约束是模型指令，不承诺几何锁定。实际表单保存、刷新与旧结果提示已通过隔离模拟浏览器验证。
- 保留现有候选采纳、丢弃、本地恢复及设计血缘，不自动覆盖源设计。
- 多视角任务可选择 1–4 个视角，Action 按所选视角顺序逐次执行图像编辑（每次一张），共用主图与参考图；全部成功后保存带视角标签的候选。中途失败不保存半套候选，也不自动重试；已经完成的外部请求仍可能计费。
- Canvas、Inspector 和候选评审显示视角标签；修改所选视角会令既有候选过期，不会自动生成。几何一致性仍需设计师评审，不能等同 CAD 或可靠三维重建。
- 局部编辑支持矩形、多边形和画笔选区；多边形明确完成后保存，画笔支持撤销最后一笔。选区绑定主图节点和素材，保存及刷新后恢复；更换素材后需重新选择。运行时将主图和同尺寸透明区域蒙版编码为 PNG Blob，通过 Action / Router 发送真实 mask，不能退化为无蒙版请求。
- Provider 设置需明确确认模型支持蒙版；连接测试不代表已验证图像编辑／多图／蒙版效果。接口拒绝时不重试、不降级。模型蒙版仅是指引；软件用同一选区栅格合成同尺寸返回图，精确保留选区外源图像素。损坏图片或尺寸不一致拒绝保存该批结果，不自动重跑；选区内语义、造型和接缝仍需评审。
- 当前项目文件 schema 为 9，Dexie 数据库版本为 7（两个不同版本）。旧格式通过版本链迁移；独立候选节点、输出边、实际输入快照及 Blob、组成员关系和精细选区纳入工程包。8→9 保留旧矩形。未来不支持的格式明确拒绝，完整性校验在替换项目之前执行。
- 画布分组通过 Action 创建／解散：按 Shift 多选未分组卡片，组标题整体拖动，成员仍可独立拖动；组框随成员位置调整，解组保留内容。仅允许同板、无重复成员的单层分组，不改变设计血缘。复制含待评审候选的组前需先采纳，避免复制候选身份。
- 智能消除为独立 `image.erase` 能力：要求真实选区蒙版，走 Action → Router → OpenAI-compatible 编辑接口；不支持或 HTTP 拒绝不退化、不重试。返回图经选区外像素保护后保存为候选，不覆盖原图。任务模式随 schema 9 工程保存。已核验模拟 HTTP、候选保护、工程往返和主应用刷新恢复；本轮未调用外部模型，实际物体移除与背景补全效果仍依赖模型评审。

## 暂缓与能力边界

- 超分辨率按用户决定列为后续项，不新增相关依赖；不能用提示词模板或普通插值冒充。
- 多视角几何一致性：已接通逐视角任务，但未完成真实模型多视角几何一致性验收，不保证普通图像编辑获得几何一致结果。
- 3D 生成、音视频生成：现有 3D 查看器不是生成服务。
- Canvas Agent、MCP、远程插件、自定义执行脚本：涉及新权限与运行时边界，不能直接并入现有应用。
